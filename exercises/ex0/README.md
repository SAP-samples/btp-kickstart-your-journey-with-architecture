## Step 1: SAP Discovery Center 
The Best starting point for any information on SAP BTP and SAP Business AI is the SAP Discovery Center.<br/>
1. Navigate to [SAP Discovery Center](https://discovery-center.cloud.sap) </br>
![Navigate to Discovery Center](./images/1.png)<br/>
2. The SAP Discovery Center is offering all kinds of information on what SAP BTP can do, how it can be used and what others are using it for. It is devided into 4 main sections:<br/> - Missions <br/> - SAP BTP Guidance Framework <br/> - The BTP Service Catalog with cost estimator <br/> - AI Scenario Catalog with cost estimator <br/>
Let's start to have a look at the SAP BTP Guidance Framework: <br/>
Press the Tile for the SAP BTP Guidance Framework
![Navigate to Guidance framework](./images/2.png)
3. The SAP BTP Guidance Framework provides a central entry point to all kinds of guidance documents for different roles like architects, developers or administrators.<br/>
Have a look at the links in the different sections of the main page of the SAP BTP Guidance Framework and get an overview about what kind of guidelines can be found in this repository.<br/>
Press the link to the SAP BTP Administrators' guide:
![Navigate to Admin Guide](./images/3.png)
